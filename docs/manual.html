🚀五分钟上手

安装、打开、让沐比送出第一条提醒。教程到这里就结束了——本页其余内容都是可选的。

  1. 安装。到 Releases 页下载：Windows 双击 .msi，macOS 把 .dmg 里的 MoveBit 拖进「应用程序」，Linux 用 .deb / .rpm / .AppImage。
  2. 首次启动。一个小巧的首启流程：定喝水间隔（30 / 45 / 60 分钟）、久坐间隔（45 / 60 / 90 分钟）、要不要提示音。选完点「开始使用」。不想选就点「跳过」，全部用默认值。
  3. 认识沐比。屏幕边缘的小家伙就是提醒本身：到点它举杯、起身、闭眼，配一句明确的健康建议。卡片几秒后收起，「做到了 / 稍后 / 隐藏」就在卡片上等你处理。
  4. 完成。关掉主窗口（Windows / macOS 缩进托盘继续计时，Linux 关窗即结束会话）。到点沐比会来找你——看一眼就懂，做不做由你。

⏱工作计时

MoveBit 统计你真正在操作电脑的活跃时间——键盘鼠标一停，计时就不再增长。

  • 看今天。主窗口左上角「今日活跃」给出今天的活跃总时长，下方是本轮久坐进度（如 12 / 45 分钟）。
  • 看趋势。「最近 7 天 / 30 天」图表显示每天的活跃分钟和休息次数，鼠标悬停看单日详情。
  • 看模式。「工作模式洞察」卡片给出当前连续工作、今日最长连续和近 30 天概况。
🚶 离开就是休息
键鼠空闲超过「离开多久算休息」（默认 5 分钟），这段时间算作真正的休息，久坐计时自动重置。

🐹沐比角色（提醒的交付方式）

到点的提醒由沐比在屏幕边缘交付：喝水举杯、起身拉伸、护眼闭眼，配一句明确的建议文字。它不锁屏、不抢焦点、不拦截输入——面板整体鼠标穿透。

  • 三种手势。久坐→起身拉伸、喝水→举小蓝杯、护眼→闭眼远眺；多个提醒同时到期会合并成一条，含义与操作全部保留。
  • 三种回应。「做到了」是自我报告（不代表实测完成），「稍后」把提醒按设定延后，「隐藏」只是收起——下个周期照常来。
  • 专注模式。演示、会议时开「专注」——托盘菜单（Windows / macOS）或主窗口头栏按钮（全平台）：提醒安静排队，退出专注后合并成一条有界汇总，绝不堆积轰炸。
  • 个性可选。「提醒设置」里可调沐比尺寸（S/M/L）、动效（静止 / 轻柔 / 活泼）、停靠位置（右下 / 左下 / 右上）与标签显示。
✅ 没有全屏强制休息
v0.0.1 起全屏强制休息已从产品移除：无论何时，提醒都不会遮盖屏幕、抢夺焦点或拦截输入。应用内提醒卡是角色卡不可用时的诚实回退（如 Wayland）。

💧护眼与喝水

两个轻量提醒：喝水按独立周期循环，护眼建议你看向远处。它们都由沐比交付，从不打断操作。

  • 喝水。「喝水提醒间隔」默认 30 分钟，到点沐比举杯；「做到了」自我报告，「稍后 N 分钟」延后，「隐藏」收起。
  • 护眼。「微休息」默认每 30 分钟一次，沐比闭上眼睛提醒你看向远处；卡片自然走完即算回应，点击或按 Esc 提前收起。
  • 提示音。「提示音」只作用于提醒出现的一刻；专注模式下一切静默。

🫗托盘与主窗口

Windows 上 MoveBit 缩在系统托盘，macOS 住在菜单栏；Linux 没有托盘，主窗口就是中心。

  • 打开设置。Windows / macOS：点托盘水滴图标打开主窗口；Linux：直接打开主窗口即可。
  • 提醒动作常在。有提醒待处理时，「做到了 / 稍后 N 分钟 / 隐藏」直接出现在提醒卡上——Windows / macOS 也可从托盘菜单触达；沐比角色与文字本身保持鼠标穿透。
  • 专注开关。「开启 / 关闭专注」随时可用：托盘菜单（Windows / macOS）或主窗口头栏按钮（全平台）；托盘菜单里也有「检查更新」和「退出 MoveBit」。
💡 关窗口 ≠ 退出
Windows / macOS：关闭主窗口只是最小化到托盘，提醒继续，真正退出走托盘菜单的「退出 MoveBit」。Linux：没有托盘，关闭主窗口即结束本次会话，数据已即时保存。

↻在线更新

更新检查默认开启：启动时一次，之后约每 6 小时一次。发现新版本后，下载、校验都由 MoveBit 完成，换新只等你一次点击。

  • 手动检查。主窗口「关于」卡片 →「检查更新」（Windows / macOS 也可从托盘菜单）。
  • 确认换新。发现新版本后点「更新并重启」——下载、SHA-256 校验自动完成后，MoveBit 退出、替换文件、重新启动。
  • 可中途取消。下载进行中点「取消下载」即可中止，当前版本不受影响，稍后仍可一键继续。
  • 自动检查可关。「关于」卡片取消「自动检查更新」勾选即可。

❓常见问题

数据存在哪？

配置和历史都在本机数据目录：macOS ~/Library/Application Support/movebit，Windows %APPDATA%\movebit，Linux ~/.config/movebit。想多设备合并统计，可在「关于」里把数据目录指到 Resilio / Syncthing 等同步文件夹，重启后生效。

需要注册账号吗？

不需要。没有账户，没有遥测；更新检查只访问 GitHub Releases。

支持哪些平台？

Windows x64、macOS（Apple silicon 与 Intel）、Linux x64 与 arm64。Linux X11 下沐比角色卡停靠显示；Wayland 会话回退为应用内提醒卡（提醒与更新照常工作）。

沐比会在 Wayland 上出现吗？

不会——Wayland 合成器不提供可靠的窗口定位与穿透保证，MoveBit 不假装能做到。Wayland 会话的提醒以应用内提醒卡交付；X11 会话角色卡正常停靠。

怎么改语言和主题？

语言：主窗口「提醒设置」最下方「语言」可选中文 / English / 跟随系统。深浅色：跟随系统外观设置（macOS「系统设置 → 外观」），应用内不再单独提供切换。

怎么卸载？

Windows：系统「设置 → 应用」卸载 MoveBit（便携版直接删目录）。macOS：把「应用程序」里的 MoveBit 拖进废纸篓。Linux：sudo apt remove movebit 或 sudo dnf remove movebit，AppImage 删文件即可。卸载不会删除数据目录；想彻底清除再手动删掉上面说的数据目录。

更新失败怎么办？

先重试一次：检查失败多半是网络问题。下载或校验失败时，MoveBit 会清掉半成品，当前版本不受影响。若提示「应用目录不可写」，说明安装位置没有写权限——装到用户目录，或改用便携版。实在不行，直接去 Releases 页手动下载安装，用户数据不会丢。
