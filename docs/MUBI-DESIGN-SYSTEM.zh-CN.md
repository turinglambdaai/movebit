## 造型比例（冻结）

画布 120×140。身体轮廓约 100×108，最宽处在中下部，圆钝收顶，下弧宽厚。两片**叶形鳍**根植头顶——左鳍升起约 16 并外倾，右鳍约 13 并略内倾；明确**不是**高耸的动物耳朵。眼：墨色椭圆约 6 宽，中心距固定 27，略高于中线。待机无嘴；仅 `ack` 出现 2 单位小弧线。旧原型（已关闭的 PR #53）的兔耳椭圆是退役美术，不是参考。

**剪影测试：** 60 逻辑像素与单色蒙版下沐比仍可辨认；S 档面部细节保持可读。

## 色彩令牌

| 令牌 | 色值 | 用途 |
| --- | --- | --- |
| `mubi.body` | `#F6EEDF` | 暖米白身体主色 |
| `mubi.body.light` / `mubi.body.deep` | `#FBF5E9` / `#E8D7BE` | 体积渐变端点（左上亮 → 右下深） |
| `mubi.shadow` | `#D8C8B5` | 形体/接触阴影——绝不作深色描边 |
| `mubi.ink` | `#2D2A28` | 眼睛与必要面部细节 |
| `mubi.fin` | `#F1E4CC` | 鳍填充 |
| `cue.water` / `cue.move` / `cue.eyes` / `cue.done` / `cue.focus` | `#62B6FF` / `#FF8C6B` / `#65C8B8` / `#F2C96B` / `#8DA1B5` | 小面积语义强调（水杯、伸展提示、远眺、闪光、专注罩） |
| `label.text.light` / `label.surface.light` | `#2D2A28` / `#FFFDFB` | 胶囊文字 / 底面 |

**深色模式独立做美术**：身体保持暖米白；各端降低边缘光不透明度（浅色 0.45 → 深色 0.30，见 `tokens.json → rendering`）并使用低眩光胶囊底面。禁止自动黑白反转。对比度目标：提醒正文 4.5:1，关键非文本 3:1；调整底面/文字，而不是假设强调色能当正文读。

## 尺寸与停靠

身体高度逻辑单位（macOS pt / WinUI 有效像素 / GTK CSS px）：**S 60 · M 78（默认）· L 104**。透明外框可为鳍/道具/气泡变大，但**身体高度是契约**；S 档做光学修正。默认停靠可见工作区右下、边距 ≥16；备选左下/右上；绝不自主越过文档中心；显示器/缩放/安全区变化时重新夹取。面板**整体鼠标穿透**（#54 兜底）——Done / 稍后 / 隐藏 / 专注走托盘与键盘。

## 动效语言

「少动，动得好」（#56 §4）。一次合并到期 → 一条提醒 → **一次**表情动作；气泡 160–220ms 淡入、停留 4–6s、180–240ms 淡出；气泡消失绝不等于提醒完成。状态：`idle`（偶发眨眼 ≤180ms、呼吸 ≤2 单位）、`water`（举杯 700–900ms）、`stand`（身体 ×1.06 底部锚定拉长 + 伸展提示，800–1100ms，位移 4–8 单位）、`eyes`（闭眼弧 + 薄荷远眺——最安静态）、`ack`（点头 + 暖色闪光 350–500ms）、`focus`（静止、安静罩、无环境动效）。Reduce Motion → 呈现实际到期种类的静态画，文字与操作不变。所有数值是设计目标，按打包实测调优。已实现：macOS 原生手势（SwiftUI）+ 待机眨眼；Windows 计时器驱动元素更新；Linux 33ms cairo 重绘——均遵守 still/subtle/lively 与 Reduce Motion。各端记录真实待机/动画渲染开销，不凭空编预算。

## 各端实现契约

- 嵌入 `assets/mubi/tokens.json → geometry` 的规范路径串（身体、鳍、眼、闭眼弧、ack 嘴）与色彩令牌；令牌映射之外**不许出现魔法色值**。
- 原生渐变替代 SVG 滤镜：身体 = 线性渐变 `body.light → body → body.deep`；边缘光 = 径向白色渐变（透明度分浅/深）；下影 = 垂直 `shadow` 渐隐；专注罩 = 径向环。
- 一个角色、参数化变换——六态必须是同一只沐比，不是六个吉祥物。
- 本地化文案在 `shared/i18n/{zh,en}.json`；绝不烤进图片。
- 设置（v1 config）：沐比尺寸 S/M/L、动效 still/subtle/lively（默认 subtle）、停靠位、气泡标签。健康提醒间隔的设置优先级高于角色定制。

## 验收

`node scripts/gen-mubi-art.mjs` 重新生成母版；contact sheet 是各端渲染的视觉验收参照（打包截图在 S/M/L、浅色/深色下与它比对）。真实验收门禁：每平台 `raco rivet acceptance --json` + #56 D4 的桌面实测清单——任何声明支持的平台缺证据就不得宣称完成。
