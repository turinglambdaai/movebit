# MoveBit 使用指南

中文 · [English](USER-GUIDE.md)

喝水、起身、护眼三类健康提醒，由屏幕边缘的小家伙沐比（Mubi）交付——永远没有全屏遮罩、没有焦点抢夺、没有输入拦截。

## 可用性

v0.0.1。MIT 许可的免费社区应用，不接商业激活或订阅。

## 平台与安装

正式发布覆盖 Windows x64、macOS（Apple silicon 与 Intel）和 Linux x64/arm64。每个平台都有便携压缩包；Windows 另有 MSI，macOS 有 DMG，Linux 有 deb、rpm 与 AppImage。请使用[官方 Releases](https://github.com/turinglambdaai/movebit/releases)，选择明确列出的系统/架构资产并核对 SHA-256 校验文件。预览资产可能缺少签名或公证；不要为安装关闭系统级安全保护。

平台说明：空闲检测使用系统原生 API（GetLastInputInfo / CoreGraphics / XScreenSaver）。Linux 上沐比角色卡在 X11 会话停靠；Wayland 合成器不允许应用自行放置穿透卡片，提醒改为应用内提醒卡投递（提醒、历史与更新照常工作）。

## 你的第一次使用

1. 安装并启动。小巧的首启流程会问三件事：喝水间隔（30/45/60 分钟）、久坐间隔（45/60/90 分钟）、要不要提示音——点「跳过」则全部用默认值。
2. 认识沐比。周期到点，角色在屏幕边缘出现，带着明确的健康建议和可操作的标签。卡片几秒后收起，「做到了 / 稍后 / 隐藏」就在卡片上等你处理。
3. 按你的方式回应：**做到了**（自我报告，不是实测）、**稍后**（按提醒间隔延后）、**隐藏**（只是收起；下个周期照常来）。三者就在提醒卡上——Windows / macOS 也能从托盘菜单触达——角色与文字保持鼠标穿透，只有操作行可点。
4. 需要后台提醒再开「开机自启」。历史图表是使用估计，不是健康测量。

## 沐比、专注与诚实

- 三种手势对应三类提醒：久坐→起身拉伸、喝水→举小蓝杯、护眼→闭眼远眺。多个提醒同时到期会合并成一条，含义全部保留。
- **专注模式**（Windows / macOS 用托盘开关，Linux 用主窗口头栏按钮）在演示、会议时静默排队提醒，结束后只送回一条有界汇总——绝不堆积。开专注前已经显示的提醒不会被重发。
- 十分钟无人回应的提醒会过期，下一条按正常周期到来。沉默不会被记成完成，也不会丢失任何提醒。
- 在设置里给沐比做个性化：尺寸 S/M/L（身体高度 60/78/104）、动效（静止/轻柔/活泼）、停靠位置、标签显示。Reduce Motion（或动效选「静止」）会让一切保持静态。
- v0.0.1 里没有任何全屏强制休息，也没有开关能把它找回来——这是有意删除的契约。

## 工作历史

今日活跃分钟、提醒次数与 7/30 天图表都在主窗口；历史保留 370 天。活跃时间只统计真实的键鼠存在——超过离席阈值（默认 5 分钟）的空闲视为一次真正的休息并重置各周期。

## 数据、备份与恢复

退出 MoveBit 后备份 `config.json` 与 `history/` 文件夹：macOS `~/Library/Application Support/movebit`，Linux `~/.config/movebit`，Windows `%APPDATA%\movebit`。v1 配置文件带 `SchemaVersion` 标记；没有标记的外来文件会回落为默认值，而不是被半吊子迁移。恢复前先在副本上验证。

## 网络、密钥与隐私

提醒与统计全部本地完成。更新检查与下载只访问 GitHub Releases。没有账户、没有遥测、不记录按键——空闲检测只向操作系统询问「距离上次输入过去了多久」，仅此而已。沐比的面板不读取任何输入。

## 更新与卸载

应用内「检查更新」读取 Ed25519 签名的 `update-manifest.json`，下载后校验大小与 SHA-256，只通过「更新并重启」换新。任何校验失败都会中止，当前安装原封不动。卸载程序不会删除独立的数据目录；删除个人数据前先确认备份。
