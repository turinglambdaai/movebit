# MoveBit 使用指南

[English](USER-GUIDE.md) · **简体中文**

配置工作休息与喝水提醒，并查看本地活动历史。

## 当前可用状态

MIT 许可的免费社区应用，不接商业激活或订阅。

## 平台与安装

提供 macOS、Windows、Linux 桌面预览。空闲检测依赖桌面会话；不支持的 Wayland 会话会回退为经过时间计时。

从[官方 Releases](https://github.com/turinglambdaai/movebit/releases)选择明确标注系统和架构的附件，阅读该版本说明并核对附带校验文件。未列出的附件或平台不视为已交付。预览构建可能没有系统发行者签名或公证；不要为安装而关闭系统安全保护。

## 第一次使用

1. 新档案默认**温和模式**：只有弹窗提醒，绝不锁屏。全屏休息只在明确开启后才会出现——首次引导中选择「标准」或「严格」，或在设置里打开「强制休息」。
2. 启用更强的全屏休息前，先测试暂停、稍后提醒与休息屏上的各个控制。
3. 需要后台提醒时再启用登录自启；7/30 天历史属于使用估计，不是健康测量。

## 休息屏与退出方式

- 全屏休息会覆盖**所有已连接显示器**并显示倒计时，倒计时结束自动解锁。
- **紧急退出永远可用**：按 <kbd>Esc</kbd> 或点击屏幕上的「紧急退出」按钮，立即在所有显示器上恢复可用窗口；即使提醒引擎暂时无响应也照样生效。
- 普通跳过按钮按配置延迟出现（默认 20 秒），点击后顺延久坐提醒。
- 离开休息不会成为惩罚：紧急退出或跳过都会顺延提醒，而不是瞬间重新锁定。退出瞬间提醒引擎不可达时，MoveBit 仍先恢复屏幕，待引擎恢复后再静默完成取消。
- 完成的休息会重置所有提醒周期，休息本身不计入工作时长。
- macOS 的「减弱动态效果」会去掉装饰性光环动画；休息屏的控件都带常规按钮文字，读屏器可以直接命名。

## 数据、备份与恢复

退出 MoveBit 后备份 config.json 与 history.json：macOS 为 ~/Library/Application Support/movebit，Linux 为 ~/.config/movebit，Windows 为 %APPDATA%/movebit。历史最多保留 370 天，恢复先在副本验证。

## 联网、密钥与隐私

提醒和计时在本地完成；更新检查与发行下载会访问外部服务。活动历史可能暴露工作习惯，分享诊断前应先检查。

## 已知限制

各安装形态的更新恢复仍在 #48 跟进。紧急退出已在三平台落地；Windows 与 Linux 上全屏控制的实机验收随各自打包腿进行。本工具提供提醒，不提供医疗建议或预防损伤保证。

## 更新与卸载

先备份数据，再阅读目标版本说明。应用内检查更新不一定能安装当前渠道的更新；按手册区分便携包、系统安装器和源码安装。不要绕过失败的验签或用来源不明的文件覆盖程序。更新失败时保留现有数据与错误信息，使用可信发行包恢复；卸载程序通常不等于删除独立的数据目录，删除个人数据前先确认备份。

## 获得帮助

在 [GitHub Issues](https://github.com/turinglambdaai/movebit/issues) 反馈，中文或英文均可。提供版本、系统与架构、安装渠道、复现步骤、预期和实际结果。先用合成样本复现；不要附上密钥、授权文件、数据库、原始私密文档或完整日志。公开支持不承诺响应时限。
