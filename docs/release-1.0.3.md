# MoveBit v1.0.3

This patch release synchronizes the forced-break experience across every connected display and promotes the new production Windows code-signing gate into the release baseline.

Highlights:

- Full countdown UI on every monitor.
- Native Arc progress driven from the same remaining-time value as the numeric countdown.
- Countdown display no longer reaches 0:00 before the break actually completes.
- Windows public release artifacts must pass Azure Artifact Signing and Authenticode verification before publication.
