# macOS 健康提醒角色视觉预览（仅供开发测试）

产品总任务：[Issue #51](https://github.com/turinglambdaai/movebit/issues/51)。依赖提示策略基础 PR #52。此切片只验证 **macOS 原生绘制与不截获输入**，不是三端已上线功能。**MoveBit 的核心仍是喝水、久坐起身和护眼提醒。** 小角色只是原有提醒事件的视觉表达，不是要做独立宠物养成、陪玩或额外索取注意力的产品。

## 如何启动

在 macOS 配好 Rivet 开发环境后：

```sh
MOVEBIT_COMPANION_PREVIEW=1 raco rivet dev
```

未设置环境变量，所有提醒照旧。自动打包验收时使用 `MOVEBIT_ACCEPTANCE=1`，即使同时设置预览变量也会强制走已有产品行为。

## 当前功能

- 原创矢量绘制的小动物，固定停靠主屏幕可用区域右下角，不横穿工作区。
- 使用不激活的 AppKit 浮动窗口，`ignoresMouseEvents = true`：**整个窗口点击穿透，不支持直接拖动或点击宠物**。交互必须等跨平台命中区域方案验证后再启用。
- 使用原有 `RemindersDue` 事件：优先级久坐 > 喝水 > 微休息，一次合并事件只展示一个动作；不增加计时器、RPC，也不改动健康统计、稍后提醒或持久化。
- 事件发生时最多短跳两次，7 秒后回到静态待机；遵循 macOS“减少动态效果”。
- 仅在预览开启时向状态栏增加“Show/Hide preview pet”，本地立即隐藏/恢复，后端失联也能操作；隐藏宠物后继续采用旧的温和提醒。
- 全屏强制休息开始时隐藏宠物；紧急退出行为仍由现有实现控制。不申请录屏、辅助功能、账号权限，不添加网络请求或引用其他产品角色素材。

## 合入前必测（尚未声称通过）

- [ ] 未设置变量：没有宠物、提醒行为完全不变。
- [ ] 开启预览：宠物固定靠边，鼠标能在它的整个 98×98 区域后方点击、拖拽、选择文字，键盘焦点保持在用户原来的应用。
- [ ] 用合成事件分别触发水、微休息、久坐和合并提醒：只出现一个宠物动作，不额外改写历史。
- [ ] 后端失联时，菜单仍可立即隐藏宠物；再次显示回到待机。
- [ ] 多显示器连接变化、切主屏、缩放、Dock/工作区域变化后仍在屏幕内。
- [ ] 测试全屏应用、演示和屏幕共享。**已知限制：不具备可靠的全屏/共享检测**，虽然没有启用“加入全部 Spaces”，但不能据此保证会议不尴尬。演示时必须手动隐藏。
- [ ] 显式开启强制休息后触发，宠物隐藏且不会干扰紧急退出。
- [ ] 开启减少动态效果，验证无跳动；检查 VoiceOver。
- [ ] 退出并不带环境变量重新启动，不应有残留配置变化。

## 暂不具备的能力

本预览没有宠物点击/拖动、持久化偏好、完整多屏停靠设置、会议检测、原生无障碍实测以及 Windows/Linux 支持；预览菜单文字暂未接入正式国际化单源。绝不能将其当作已发布成品或默认开启。

后续先验证真实交互命中区与专注模式，再接设置持久化、中英文正式 UI、三平台宿主与 Wayland 安全降级。只有原生构建、打包验收及用户可操作性证据齐全后才推进默认开启。
