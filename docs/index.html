核心差异

不是又一个被你顺手关掉的计时器。

MoveBit 围绕三件事设计：只累计真正重要的活跃时间、让提醒以不被忽略又不打断的方式出现、识别你实际离开工位的休息。

平台支持

跨平台，但把不同平台的差异说清楚。

当前正式发布支持 Windows x64（ARM64 Windows 通过模拟运行 x64 构建）、Apple silicon 与 Intel 的 macOS，以及 Linux x64 与 arm64。每个平台都有便携压缩包；Windows 与 macOS 额外提供 MSI/DMG 安装器，Linux 提供 deb、rpm 与 AppImage。Linux X11 下沐比角色卡可停靠显示；Wayland 会话诚实回退为系统通知。

FAQ

安装之前，值得先说清楚的问题。

选安装版还是便携版？

日常长期使用推荐安装版：Windows MSI 或 macOS DMG。它给 MoveBit 一个稳定的位置、开始菜单/启动台入口和标准卸载。临时使用、U 盘、受管电脑不希望安装，或者你偏爱便携软件时再选便携 ZIP、Linux tar.gz 或 AppImage。

MoveBit 支持在线更新吗？

支持。「检查更新」读取 Ed25519 签名的 update-manifest.json，发现新版本后下载并做 SHA-256 校验，全部通过再由你点击「更新并重启」完成换新。任何一步校验失败都会中止，当前版本原封不动。

还有全屏强制休息吗？

没有。v0.0.1 起全屏强制休息已从产品中移除：提醒由屏幕边缘的沐比角色或系统通知交付，永远不会遮盖屏幕、抢夺焦点或拦截输入。

MoveBit 会记录我输入或点击了什么吗？

不会。空闲检测模块只向操作系统询问距离上次用户输入过去了多久；提醒逻辑需要空闲时长，而不是按键、文档或点击内容。

Linux Wayland 下会怎样？

提醒与在线更新照常工作。Wayland 合成器不提供可靠的窗口定位与穿透保证，因此沐比角色卡在 X11 会话停靠，Wayland 会话诚实回退为系统通知。

需要另外安装别的运行时吗？

使用打包 Release 时不需要。MoveBit 自带所需的一切——Linux 上唯一的外部依赖是 GTK 4 及其系统库。

为什么 Windows 或 macOS 可能对下载文件发出警告？

当前社区构建尚未签名。代码签名 / 公证属于额外的发布者身份信号，也是下一项重要的分发体验改进。

椅子不算健身计划。

MoveBit 在你工作时保持安静，到点由沐比送上一句明确的健康建议——看一眼就懂，做不做由你；升级与启动的麻烦也从日常里拿掉了。
