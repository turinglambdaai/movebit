FAQ

The questions worth answering before install.

Installer or portable archive?

For normal daily use, choose the installer.

Does MoveBit update itself?

Yes — via the published feed; the flow differs by host.

Is a forced break the same as locking my computer?

No. MoveBit uses topmost full-screen application windows.

Does MoveBit record what I type or click?

No. MoveBit needs elapsed idle duration, not input contents.

What happens on Linux Wayland?

MoveBit falls back to elapsed-time reminders when a supported global idle source is unavailable.

Do I need to install anything else first?

No for packaged releases.

Why might Windows or macOS warn about the download?

The current community builds are unsigned.

Your chair is not a workout plan.

MoveBit stays quiet while you work and becomes hard to ignore only when a real break is due.
