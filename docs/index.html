The difference

Not another timer you dismiss without moving.

MoveBit is built around three ideas: count the time that matters, recognize real time away from the desk, and make the important break deliberate.

A calmer system

One honest clock. Three different kinds of interruption.

Long sit breaks, micro breaks and water reminders are separate cycles.

01Work normally

MoveBit lives in the tray and accumulates active time quietly.

02Small nudges stay small

Micro breaks use a light center-screen prompt; water uses a toast.

03Long work earns a real break

The forced-break view owns the moment, suppressing lower-priority reminders until it finishes.

04Come back with clean cycles

Completed breaks reset the reminder cycles; forced-break time is not counted as work.

Trust by design

It watches the clock, not your work.

A health utility should not need your documents, keystroke contents or an online account just to know when you've been at the computer too long.

Local-first by default.

MoveBit stores its configuration and history on your machine. The reminder system works without a cloud service or sign-in.

✓Idle duration, not key contentsNative platform idle APIs provide elapsed idle time.
✓No global keyboard / mouse lockThe forced break is a topmost app window, not an OS input hook.
✓Atomic local persistenceConfiguration and history use write-then-replace persistence.

FAQ

The questions worth answering before install.

Is a forced break the same as locking my computer?

No. MoveBit uses topmost full-screen application windows for the break experience.

Does MoveBit record what I type or click?

The idle providers ask the operating system how long it has been since user input.

What happens on Linux Wayland?

MoveBit falls back to elapsed-time reminders when a supported global idle source is unavailable.

Do I need to install .NET?

No for the packaged releases. MoveBit publishes self-contained builds.

Can I skip a forced break?

Yes, if skipping is enabled. The skip control appears after a configurable delay.

Why might Windows or macOS warn about the download?

The current community builds are unsigned.

Your chair is not a workout plan.

MoveBit stays quiet while you work, notices when you genuinely step away, and becomes hard to ignore only when a real break is due.
